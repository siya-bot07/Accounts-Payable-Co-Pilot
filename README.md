🚀 Features
📄 AI Extraction: Instantly reads unstructured PDF invoices and converts them into structured JSON data using Sarvam AI.

🔗 ERP Validation: Automatically cross-references the extracted PO Number, Vendor, and Total Due against an internal SQLite database.

⚡ Real-Time Status: Instantly flags invoices as ✅ Approved, ⚠️ Flagged, or ❌ Rejected based on database matches, eliminating manual review.

💻 Modern Dashboard: A clean, drag-and-drop web interface built for quick processing.
